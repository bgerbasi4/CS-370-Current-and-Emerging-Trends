# CS-370-Current-and-Emerging-Trends
Project Overview

For this project, I developed an intelligent pirate agent that learned how to navigate a maze and find treasure using deep Q-learning. Some of the code was provided as starter code, including the game environment, experience replay functionality, and supporting methods needed to run and interact with the maze. My main responsibility was completing the deep Q-learning portion of the project and training the pirate agent. I created the training logic that allowed the agent to choose actions, learn from previous experiences, update its neural network, and gradually improve its ability to reach the treasure. Through testing and training, I was able to apply concepts involving reinforcement learning, neural networks, exploration, exploitation, rewards, and experience replay.

What Do Computer Scientists Do and Why Does It Matter?

Computer scientists use technology, algorithms, and problem-solving skills to develop solutions to many different types of problems. Their work can involve areas such as software development, artificial intelligence, cybersecurity, databases, and data analysis. This matters because computer systems are used in almost every part of modern life. This course showed me that computer science is not only about writing code. It also involves understanding a problem, determining which approach is appropriate, testing possible solutions, and considering how the finished system could affect the people who use it.

How Do I Approach a Problem as a Computer Scientist?

I approach a problem by first understanding what needs to be accomplished and then breaking the larger problem into smaller pieces. In the pirate intelligent agent project, the overall goal was for the pirate to successfully reach the treasure. Instead of focusing only on the final goal, I had to consider the possible actions available to the agent, how rewards and penalties affected its behavior, how previous experiences could be used for learning, and how to balance exploration with exploitation. I also learned the importance of testing, reviewing results, and adjusting a solution when it does not behave as expected. This process can be applied to problems beyond artificial intelligence because it encourages an organized and logical approach to problem-solving.

What Are My Ethical Responsibilities to the End User and the Organization?

As a computer scientist, I have a responsibility to create systems that are reliable, secure, fair, and designed with the end user in mind. AI systems require additional attention because their decisions can be influenced by their training data, objectives, and the way rewards are designed. Developers should consider issues such as privacy, security, bias, transparency, and unintended outcomes before deploying an AI system. I also have a responsibility to the organization to develop solutions that meet its requirements without ignoring risks or negatively affecting users. This course helped me understand that creating an AI system is not only about whether the system works, but also whether it is being used responsibly and appropriately.
